# Practice index: the facilab.ru library

Every card of the «Библиотека фасилитатора» at facilab.ru as of 2026-11-26: 191 practices,
grouped by the first stage the library files them under. This file is an index only: the
one-line gloss says what the practice is, not how to run it. How to use the index, how to
open a card and the short list with mechanics are in `practices.md`.

Card address: `http://facilab.ru/cards/<id>`. Group size and time are quoted from the card.
A practice whose label on the site differs from its name carries the label in brackets.
